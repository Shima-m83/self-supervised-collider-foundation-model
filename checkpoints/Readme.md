# Model Checkpoints

The trained Transformer checkpoint is not committed to the repository because model checkpoint files can be relatively large.

The notebooks expect the best checkpoint at:

```text
checkpoints/best_model.pt
```

The checkpoint contains the trained state of the Masked Particle Transformer.

The model configuration used in the current study is:

| Parameter               |    Value |
| ----------------------- | -------: |
| Input feature dimension |        7 |
| Embedding dimension     |      128 |
| Attention heads         |        8 |
| Transformer layers      |        4 |
| Feed-forward dimension  |      512 |
| Dropout                 |      0.1 |
| Masking ratio           |      40% |
| Optimizer               |     Adam |
| Learning rate           | 1 × 10⁻⁴ |

The checkpoint can be regenerated by running Notebook 03.
