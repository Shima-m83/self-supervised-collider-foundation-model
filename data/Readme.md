# Data

The project uses collider events stored in ROOT/EDM4HEP format.

The raw collider dataset is **not included in this repository** because of file size and data-management considerations.

The notebooks expect the relevant ROOT input file to be available locally.

## Input data

The analysis was developed using EDM4HEP-compatible collider event data.

The main preprocessing workflow is:

```text
EDM4HEP ROOT file
        ↓
final-state particle selection
        ↓
particle kinematic variables
        ↓
PDG-ID vocabulary
        ↓
event-level train/validation/test split
        ↓
normalized particle features
        ↓
PyTorch dataset
```

The processed dataset generated by Notebook 02 is saved locally as:

```text
processed_collider_events.pt
```

This file is generated by the preprocessing notebook and is not committed to the repository.
